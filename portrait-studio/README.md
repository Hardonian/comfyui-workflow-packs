# ComfyUI Portrait Studio

**5 specialized portrait photography workflows — headshots, fashion, lifestyle, artistic, beauty.**

Battle-tested on real GPU hardware (RTX 3060, SDXL). Drag-and-drop ready.

## What's Included

| Workflow | Best For |
|----------|----------|
| **Headshot** | Corporate, LinkedIn, professional profiles |
| **Fashion** | Editorial, Vogue style, dramatic lighting |
| **Lifestyle** | Natural outdoor, candid, golden hour |
| **Artistic** | Rembrandt lighting, Renaissance, oil painting |
| **Beauty** | Cosmetic commercial, magazine cover, flawless skin |

**Includes:** 5 workflow JSONs + 5 prompt presets + 5 sample images

## Quick Start

1. Download and extract
2. Open ComfyUI → drag any `.json` workflow into canvas
3. Edit the positive prompt (node "6") to describe your subject
4. Click Queue Prompt

## Requirements

- ComfyUI + any SDXL checkpoint + GPU with ≥8GB VRAM
