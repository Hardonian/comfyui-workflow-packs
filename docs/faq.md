# FAQ — ComfyUI Workflow Packs

## General

**Q: Do I need prompt engineering skills?**
A: No. Each workflow has pre-configured nodes — just edit the prompt text and queue.

**Q: What SDXL checkpoints work best?**
A: Any SDXL 1.0 checkpoint. We recommend:
- **Juggernaut XL** — best for photography and realistic images
- **RealVisXL** — excellent for product photos
- **DreamShaper XL** — great for creative and artistic work

**Q: Can I use these commercially?**
A: Yes. All workflow packs include a personal and commercial use license. No attribution required.

**Q: Do I need ControlNet models?**
A: Only for the Controlnet Essentials Pack. All other packs work with just a base SDXL checkpoint.

**Q: Can I modify the workflows?**
A: Absolutely. The JSON files are fully editable in ComfyUI's visual editor. Customize prompts, settings, and node configurations.

## Technical

**Q: What GPU do I need?**
A: Any GPU with ≥8 GB VRAM. NVIDIA RTX 3060 or better recommended. AMD (ROCm) and Apple Silicon also supported.

**Q: How much disk space do I need?**
A: Each SDXL checkpoint is ~6-7 GB. Workflow JSON files are tiny (<1 MB each).

**Q: Can I run multiple workflows simultaneously?**
A: ComfyUI processes one workflow at a time per instance. Run multiple ComfyUI instances for parallel generation.

**Q: What image resolutions are supported?**
A: SDXL works best at 1024×1024 and its aspect ratio variants (768×1344, 832×1216, etc.). Each workflow is pre-configured with optimal dimensions.

**Q: Can I use SD 1.5 checkpoints?**
A: No. These workflows are designed for SDXL architecture. SD 1.5 models use different node configurations.
