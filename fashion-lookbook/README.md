# ComfyUI Fashion Lookbook Kit

**5 fashion-specific portrait workflows — editorial, streetwear, minimalist, vintage, luxury.**

Portrait orientation (1024×1344) optimized for fashion photography. Battle-tested on RTX 3060, SDXL.

## Workflows

| Style | Best For |
|-------|----------|
| **Editorial** | Vogue-style, dramatic lighting, avant-garde |
| **Streetwear** | Urban, casual, hip-hop culture |
| **Minimalist** | Scandinavian, clean, white-on-white |
| **Vintage** | 1970s, film grain, Kodak Portra colors |
| **Luxury** | Evening gowns, opulent settings, chandelier lighting |

**Includes:** 5 workflow JSONs + 5 prompt presets + 5 sample images

## Requirements
- ComfyUI + any SDXL checkpoint + GPU with ≥8GB VRAM
