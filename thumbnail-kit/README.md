# ComfyUI Thumbnail Creator Kit

**5 platform-optimized workflows for YouTube, podcast, social media, blog, and e-commerce thumbnails.**

Battle-tested on real GPU hardware (RTX 3060, SDXL). Drag-and-drop ready.

## What's Included

| Workflow | Resolution | Best For |
|----------|-----------|----------|
| **YouTube** | 1280×720 | Video thumbnails, clickbait, gaming |
| **Podcast** | 1024×1024 | Cover art, episode graphics |
| **Social** | 1080×1080 | Instagram, Facebook, LinkedIn |
| **Blog** | 1200×630 | Featured images, OG images |
| **E-commerce** | 1200×628 | Product banners, hero images |

**Includes:** 5 workflow JSONs + 5 prompt presets + 5 sample images

## Quick Start

1. Download and extract
2. Open ComfyUI → drag any `.json` workflow into canvas
3. Edit the positive prompt (node "6") to describe your content
4. Click Queue Prompt

## Requirements

- ComfyUI + any SDXL checkpoint + GPU with ≥8GB VRAM
